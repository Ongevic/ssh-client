# SSH Client Suite

Unified local home for the SSH/SFTP tools.

## Main tools

- Terminal client (Rust TUI, the main client): `ssh_grabber_rs`, started by `launch-tui.cmd`. The Python GUI (`ssh_client.py`) is the older client.
- Rust terminal UI: `ssh_grabber_rs\target\release\ssh_grabber_rs.exe`
- TUI launcher: `launch-tui.cmd`
- Remote mount helper: `remote-mount.ps1`
